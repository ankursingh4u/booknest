# BookNest

Appointment Booking & Scheduling for Shopify.

BookNest turns any Shopify product into a bookable service. Bookings flow
through native Shopify checkout, so payments, tax, multi-currency, deposits
and POS all come from the platform.

## Stack
TypeScript · React Router 7 + Polaris + App Bridge · Prisma + PostgreSQL
· Luxon · pg-boss · Resend · Vitest · Fly.io

## Quick start
```bash
pnpm install
cp .env.example .env
pnpm db:migrate
pnpm dev
```
